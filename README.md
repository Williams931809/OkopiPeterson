# OKOPI PETERSON
Luxury outerwear concept website blending classic fashion-house elegance with contemporary streetwear.

## Run
Static HTML/CSS/JS. Open index.html or deploy the repository to Vercel as an Other/static project (no build command, output directory .).

## Status
Responsive homepage, category filtering, product cards, and local shopping bag implemented. All products/prices are placeholders; photography is illustrative. Checkout is deliberately disabled: no real payment is processed.

## Before public launch
Provide original licensed product photography/videos, real inventory and pricing, size charts, return/shipping policies, legal pages, contact details, and implement secure Paystack checkout with a backend, server-side price verification, signed webhook verification, order database, and admin management.
